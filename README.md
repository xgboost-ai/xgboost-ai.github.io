# XGBoost Project Homepage

This site uses the GitHub Pages-supported [Minima theme](https://github.com/jekyll/minima).

## Run locally

After installing Ruby and Bundler, run:

```bash
bundle install
./serve_local.sh
```

Open <http://127.0.0.1:4000/>. The local server watches for content and style
changes; restart it after editing `_config.yml`.

If port 4000 is already in use, run `./serve_local.sh --port 4001` instead.
